# 老婆护士排班助手

一个本地运行的手机网页 App，用 HTML、CSS、JavaScript 编写。

## 打开方式

双击 `index.html` 即可在浏览器中使用。

## 功能

- 支持早班、下午班、晚班、夜班四种班次。
- 支持休息班次。
- 可以手动添加每天排班。
- 首页自动识别今天日期，显示今日班次、上班时间、下班时间和距离上班时间。
- 根据班次显示温馨提醒。
- 首页显示未来 7 天排班。
- 支持设置恋爱纪念日、结婚纪念日、生日等纪念日。
- 排班数据保存在浏览器 `localStorage`，刷新页面后仍然保留。
- 支持部署到公网后添加到手机主屏幕。

## 文件

- `index.html`：页面结构
- `styles.css`：手机端粉色情侣风样式
- `app.js`：排班、本地保存、倒计时逻辑
- `manifest.webmanifest`：手机 App 安装信息
- `sw.js`：离线缓存
- `icon.svg`：应用图标
- `DEPLOY-CN.md`：中国境内部署说明
